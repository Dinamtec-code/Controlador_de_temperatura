# Hardware

Esta carpeta contiene los archivos de hardware del controlador de temperatura.

## Estructura
- `pcb/` - Esquemáticos, layout, gerber y documentación PCB
- `mecanical/` - Modelos CAD, planos STL, archivos de manufactura

## Futuro
- CircuitMaker exports (.cmp, .cms) → PDF para documentación
- Autodesk Inventor (.iam, .ipt) → Exportar STL para repositorio
- Gerber files para fabricación PCB
