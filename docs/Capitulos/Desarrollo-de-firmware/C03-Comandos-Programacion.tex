\chapter{Comandos de programación}
\label{cp:scpi-commands}

Este capítulo describe el conjunto de comandos SCPI implementados en el \textit{firmware}. Los comandos se organizan en grupos funcionales y a continuación se describen en orden alfabético.

\section{Descripciones de comandos}
\label{sec:cmd-desc}

En todos los comandos que incluyen el sufijo \texttt{<n>}, este parámetro
representa el número de canal (1 o 2).

\subsection*{*CLS (Set Only)}

Borra todos los registros de evento y la cola de errores del instrumento. Este comando no modifica los parámetros de funcionamiento ni las salidas.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*CLS}

\subsubsection*{Ejemplo}
\texttt{*CLS}

El comando limpia todos los registros de estado. No produce respuesta.

\subsection*{*ESE (Set Only)}

Habilita bits en el registro de habilitación de evento estándar. Los bits habilitados permiten que los eventos correspondientes del registro de evento estándar se reflejen en el bit ESB del byte de estado.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*ESE <máscara>}

\subsubsection*{Parámetros}
\texttt{<máscara>} = valor entero entre 0 y 255.

\subsubsection*{Ejemplo}
\texttt{*ESE 36}

El comando habilita los bits de error de comando (32) y de ejecución (4). El instrumento no genera respuesta.

\subsection*{*ESE? (Query Only)}

Devuelve el valor actual del registro de habilitación de evento estándar.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*ESE?}

\subsubsection*{Respuesta}
Entero entre 0 y 255.

\subsubsection*{Ejemplo}
\texttt{*ESE?}

La consulta devuelve el valor programado, por ejemplo \texttt{36}.

\subsection*{*ESR? (Query Only)}

Lee y borra el registro de evento estándar. Cada bit indica un tipo de evento ocurrido desde la última lectura.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*ESR?}

\subsubsection*{Respuesta}
Entero entre 0 y 255.

\subsubsection*{Ejemplo}
\texttt{*ESR?}

La consulta devuelve \texttt{0} si no se ha producido ningún evento desde la última lectura.

\subsection*{*IDN? (Query Only)}

Devuelve la cadena de identificación del instrumento.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*IDN?}

\subsubsection*{Respuesta}
\texttt{DF,CONTROL DE TEMPERATURA,CT2CH,v1.1}

\subsubsection*{Ejemplo}
\texttt{*IDN?}

La consulta devuelve la identificación completa del instrumento.

\subsection*{*OPC (Set Only)}

Establece el bit OPC del registro de evento estándar cuando todas las operaciones pendientes han finalizado.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*OPC}

\subsubsection*{Ejemplo}
\texttt{*OPC}

El comando permite sincronizar la ejecución de comandos. No genera respuesta.

\subsection*{*OPC? (Query Only)}

Devuelve \texttt{1} cuando todas las operaciones pendientes han finalizado.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*OPC?}

\subsubsection*{Respuesta}
\texttt{1}

\subsubsection*{Ejemplo}
\texttt{*OPC?}

La consulta devuelve \texttt{1} únicamente cuando el instrumento ha completado todas las operaciones pendientes.

\subsection*{*RST (Set Only)}

Restaura el instrumento a sus valores predeterminados. Apaga todas las salidas, carga los parámetros de fábrica del PID y el \textit{setpoint}, y limpia los registros de estado IEEE~488.2.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*RST}

\subsubsection*{Ejemplo}
\texttt{*RST}

El comando devuelve el instrumento a su estado de fábrica. No produce respuesta.

\subsection*{*SRE (Set Only)}

Habilita bits en el registro de habilitación de petición de servicio.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*SRE <máscara>}

\subsubsection*{Parámetros}
\texttt{<máscara>} = valor entero entre 0 y 255.

\subsubsection*{Ejemplo}
\texttt{*SRE 32}

El comando habilita la petición de servicio para eventos del registro de evento estándar.

\subsection*{*SRE? (Query Only)}

Devuelve el valor actual del registro de habilitación de petición de
servicio.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*SRE?}

\subsubsection*{Respuesta}
Entero entre 0 y 255.

\subsubsection*{Ejemplo}
\texttt{*SRE?}

La consulta devuelve el valor programado, por ejemplo \texttt{32}.

\subsection*{*STB? (Query Only)}

Lee el byte de estado del instrumento.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*STB?}

\subsubsection*{Respuesta}
Entero entre 0 y 255.

\subsubsection*{Ejemplo}
\texttt{*STB?}

La consulta devuelve el resumen de los registros de evento; por ejemplo
\texttt{0}.

\subsection*{*TST? (Query Only)}

Ejecuta una autocomprobación interna y devuelve el resultado.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*TST?}

\subsubsection*{Respuesta}
\texttt{0} si no se detectaron fallos; \texttt{1} en caso contrario.

\subsubsection*{Ejemplo}
\texttt{*TST?}

La consulta devuelve \texttt{0} cuando el instrumento no presenta errores internos.

\subsection*{*WAI (Set Only)}

Suspende la ejecución de comandos hasta que todas las operaciones
pendientes hayan finalizado.

\subsubsection*{Grupo}
Comandos comunes IEEE~488.2

\subsubsection*{Sintaxis}
\texttt{*WAI}

\subsubsection*{Ejemplo}
\texttt{*WAI}

El comando garantiza que los comandos siguientes se ejecuten después de que terminen las operaciones en curso.

\subsection*{MEASure:TEMPerature<n>? (Query Only)}

Devuelve la temperatura medida por el sensor \texttt{<n>} en grados Celsius.

\subsubsection*{Grupo}
Medición

\subsubsection*{Sintaxis}
\texttt{MEASure:TEMPerature<n>?}

\subsubsection*{Parámetros}
\texttt{<n>} = 1 o 2.

\subsubsection*{Respuesta}
\texttt{<NR3>} (valor decimal en grados Celsius).

\subsubsection*{Ejemplo}
\texttt{MEAS:TEMP1?}

La consulta devuelve \texttt{24.7} si el sensor 1 mide 24,7~°C.

\subsection*{OUTPut<n>:STATe}

Activa o desactiva la etapa de potencia del canal \texttt{<n>}. La protección del sensor tiene prioridad: aunque se ordene \texttt{ON}, la salida no se activará si la protección de temperatura correspondiente está
disparada.

\subsubsection*{Grupo}
Salidas físicas

\subsubsection*{Sintaxis}
\texttt{OUTPut<n>:STATe <ON|OFF>}\par
\texttt{OUTPut<n>:STATe?}

\subsubsection*{Parámetros}
\texttt{<n>} = 1 o 2.

\subsubsection*{Respuesta (formato de consulta)}
\texttt{ON} u \texttt{OFF}.

\subsubsection*{Ejemplo}
\texttt{OUTP1:STAT ON}\par
\texttt{OUTP1:STAT?}

El primer comando activa la salida del canal 1. La consulta devuelve \texttt{ON} si la salida está efectivamente activa.

\subsection*{SENSe<n>:TEMPerature:PROTection:MAX}

Establece o consulta el límite superior de protección del sensor \texttt{<n>}. Si la temperatura medida supera este valor, la salida correspondiente se desactiva automáticamente.

\subsubsection*{Grupo}
Configuración de sensor

\subsubsection*{Sintaxis}
\texttt{SENSe<n>:TEMPerature:PROTection:MAX <valor>}\par
\texttt{SENSe<n>:TEMPerature:PROTection:MAX?}

\subsubsection*{Parámetros}
\texttt{<n>} = 1 o 2. \texttt{<valor>} = temperatura en °C.

\subsubsection*{Respuesta (formato de consulta)}
\texttt{<NR3>} en grados Celsius.

\subsubsection*{Ejemplo}
\texttt{SENS1:TEMP:PROT:MAX 120}\par
\texttt{SENS1:TEMP:PROT:MAX?}

El primer comando fija el límite superior en 120~°C. La consulta devuelve
\texttt{120.0}.

\subsection*{SENSe<n>:TEMPerature:PROTection:MIN}

Establece o consulta el límite inferior de protección del sensor
\texttt{<n>}. Si la temperatura medida desciende por debajo de este valor,
la salida correspondiente se desactiva automáticamente.

\subsubsection*{Grupo}
Configuración de sensor

\subsubsection*{Sintaxis}
\texttt{SENSe<n>:TEMPerature:PROTection:MIN <valor>}\par
\texttt{SENSe<n>:TEMPerature:PROTection:MIN?}

\subsubsection*{Parámetros}
\texttt{<n>} = 1 o 2. \texttt{<valor>} = temperatura en °C.

\subsubsection*{Respuesta (formato de consulta)}
\texttt{<NR3>} en grados Celsius.

\subsubsection*{Ejemplo}
\texttt{SENS1:TEMP:PROT:MIN -10}\par
\texttt{SENS1:TEMP:PROT:MIN?}

El primer comando fija el límite inferior en -10~°C. La consulta devuelve
\texttt{-10.0}.

\subsection*{SENSe<n>:TEMPerature:PROTection[:STATe]}

Activa o desactiva la banda de protección del sensor \texttt{<n>}.

\subsubsection*{Grupo}
Configuración de sensor

\subsubsection*{Sintaxis}
\texttt{SENSe<n>:TEMPerature:PROTection[:STATe] <ON|OFF>}\par
\texttt{SENSe<n>:TEMPerature:PROTection[:STATe]?}

\subsubsection*{Parámetros}
